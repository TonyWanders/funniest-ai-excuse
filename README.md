A program that writes one funny one-line excuse an AI agent gives after failing a task to `/output/entry.txt`, for the make.fun competition [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

## Run it

```sh
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The excuse is 110 characters, inside the 1 to 200 gate.
